# Contributing Guidelines

## Introduction
Thank you for considering contributing to simple-git! We appreciate your help in making this project better.

## Getting Started
To get started, please fork the repository and create a new branch for your changes. Once you've made your changes, submit a pull request to the main repository.

## Code Style
Please follow the standard JavaScript coding style. Use 2 spaces for indentation and keep lines under 80 characters.

## Commit Messages
Commit messages should be descriptive and follow the standard GitHub guidelines. Use the imperative mood (e.g. 'Fix bug' instead of 'Fixed bug') and keep the first line under 50 characters.

## Pull Requests
Pull requests should include a clear description of the changes made and why they were necessary. Please include any relevant tests or examples to demonstrate the changes.

## Issues
If you find a bug or have a feature request, please submit an issue on the GitHub issue tracker. Include as much detail as possible, including any relevant code or error messages.

## License
By contributing to simple-git, you agree to release your contributions under the MIT license.

## Thanks
Thanks again for your contribution! We're excited to see what you've made.
